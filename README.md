# 📈 StockIQ — AI-Powered Stock Market Intelligence Dashboard  

**A web-based stock analysis platform that doesn't just show data — it explains what the data means.**    
Built for beginner investors, students, and retail traders who want insights, not just charts.

## 🧠 The Problem It Solves

Most platforms like Zerodha or Yahoo Finance show raw numbers and charts — but give **zero explanation**.

> *"RSI is 74... so what do I do?"*    
> *"MACD crossed over... is that good or bad?"*

**StockIQ answers those questions** using Claude AI to generate plain-English insights.



## ✨ Features

| Feature | Description |
|---|---|
| 📊 Price Charts | MA50, MA200, RSI, MACD, Bollinger Bands |
| 🕯️ Candlestick | OHLC chart for last 25 sessions |
| 🤖 AI Insight Engine | 5 modes — Overview, Deep Analysis, Buy or Wait?, Risk, Beginner |
| 📰 Sentiment Analysis | NLP scoring of news — Bullish / Bearish / Neutral |
| 📈 Price Prediction | Linear Regression with 95% confidence bands |
| ⚖️ Risk Metrics | Sharpe Ratio, Sortino, Max Drawdown, Beta |
| 🔁 Stock Comparison | Normalized performance + correlation analysis |
| 💼 Portfolio Tracker | Real-time P&L, allocation pie chart |
| 💬 AI Chatbot | Explains RSI, MACD, Candlesticks in simple language |
| 🌡️ Sector Heatmap | 8 sectors color-coded by YTD performance |



## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | HTML5, CSS3, Vanilla JavaScript |
| Charts | Chart.js 4.4.1 |
| AI Engine | Claude Sonnet API (Anthropic) |
| Data | Simulated NSE India — 252 trading days |
| Hosting | GitHub Pages |


## ▶️ How to Run

**Option 1 — Simplest**
Download the HTML file and open it in any browser. That's it!

**Option 2 — VS Code**
1. Install **Live Server** extension
2. Right-click the file → Open with Live Server
